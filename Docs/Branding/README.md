# Boss Fight Framework branding

The pack uses a graphite, warm ivory, and ember palette to match the framework's combat and authoring focus.

## Files

- `mark.svg` — standalone emblem for avatars, icons, and small UI placements.
- `wordmark-dark.svg` / `wordmark-light.svg` — horizontal lockups for dark and light backgrounds.
- `social-preview.svg` — editable 1280 × 640 GitHub social preview source.
- `social-preview.png` — raster export to upload in the repository's GitHub social preview settings.
- `arena-background.png` — source illustration used by the social preview.
- `icon-512.png` / `icon-128.png` — square emblem exports for GitHub, package pages, and profile use.
- `icon-circle-512.png` — circular avatar export.

## Palette

| Role | Color |
| --- | --- |
| Graphite | `#17191C` |
| Warm ivory | `#F4F0E8` |
| Ember | `#F5A642` |
| Deep ember | `#D45B2C` |
| Cool accent | `#88C9D2` |

Use the SVG source files when a vector is accepted. The PNG exports are ready for services that require raster images. Keep clear space around the mark equal to the width of one outer frame stroke.
